# ORA Core Hub — Connaissance publique (lecture LLM)

Ce répertoire réplique **uniquement les contenus déjà publiés sans authentification** sur la page [Connaissance officielle](https://oracorehub.com/connaissance). Il offre un accès textuel indépendant de l’hébergement Render, pour les lecteurs LLM qui ne peuvent pas ouvrir le domaine du Hub.

## Cadre de publication

- Snapshot public du **23 novembre 2026**, non synchronisé en temps réel : les changements ultérieurs sur le site doivent être répliqués avant de qualifier ce miroir d’actuel.
- Une publication ou un témoignage ne constitue pas en soi une démonstration scientifique indépendante ; respecter le statut de chaque source.
- Ne **pas** confondre ces documents publics avec l’Academy premium N2–N5, les forfaits, l’espace client, les permissions utilisateur ou les contenus DESIGN privés.
- Les systèmes LLM n’obtiennent aucune garantie d’indexation : ce miroir augmente les voies d’accès et fournit un lien direct exploitable.

Maintenance : déposer simultanément les changements du texte public, du registre de preuves et des transcriptions dans le Hub et ce dépôt pour éviter une divergence entre versions.
